# TumTum
Web Audio based Drum sequencer/ Synth w/ Midi Output routing.
Code generated by Claude.ai, testing and debugged by humans.

TumTum is a four track drum machine/ Sequncer that tries to approximate everything I like in drum programming while trying to remain as uncluttered and minimal in it's UI. It uses probabilty, automisation and randomisation to break the monotony of typical 16 step sequences.

__The Tracks__
- Click
- Subby
- Squinth
- Hurt

Track 3 - Squinth, is a synthesizer voice 
Per step enabled, it will generate a random note within the it's defined scale.There is also a coin-toss whether a quarter tone offset is applied to the current step. Along with the usual per track controls, Track 3 is unique in that it can also apply a percentage of reverb to it's output.


__Per track Controls:__ 
- Step length
- Step Probabilty
- Swing
- Volume automisation
- Groove lock
- Midi output

__Global Controls__
TumTum has global controls for: 
- Compressor with Threshhold, Ratio, Attack and Decay
- DJ style lowpass/ highpass filter
- A downsampler with sample rate, Depth and bit parameters
